       What are Local Assignment Options?
     Provisions within Education Code (EC) and
     Title 5 Regulations (T5) that provide local
     educational agencies (LEAs) with educator
     assignment options that can be used when
     an LEA is unable to assign a certificated
     employee with the appropriate credential.

2




    Local Assignment Option Responsibilities
     The Commission:
     ◦Collects LAOs annual usage data through the California
      Statewide Assignment Accountability System (CalSAAS)
     ◦Provides Limited Guidance
     Local Education Agencies
     ◦Everything else

      Local Assignment Options are used at the discretion
                 of Local Educational Agencies

    ◦ Most LAOs require governing board action to authorize the
      assignment
    ◦ Board Action should be taken prior to the start of the
      educator’s assignment
    ◦ Usage of LAO should be acknowledged as a matter of public
      record
    ◦ Board approval needs to be given each time an assignment is
      authorized via LAO, even if educator was authorized for prior
      assignments

           practice due diligence to ensure the educator meets the
